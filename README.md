# Folio 名片設計工作室

可自由編輯、預覽並匯出雙面名片的靜態網頁。

網站：https://kevin-1215.github.io/card-studio/

直接開啟 index.html 亦可離線使用，不需安裝相依套件。

- 編輯品牌、公司、姓名、職稱與聯絡資料
- 上傳 PNG / JPG / SVG Logo，調整 Logo 大小與位置
- 移除 Logo 時自動改為文字品牌版式
- 四款配色、自訂色彩、直橫式、字型、字級與安全邊界
- PNG（依 300 dpi 換算像素）、SVG、瀏覽器另存 PDF
- 瀏覽器自動儲存與 JSON 設計檔備份／載入

內容及上傳圖片只保存在使用者瀏覽器，不會上傳至伺服器。輸出為 RGB、無出血，正式印刷請另確認 CMYK、出血及字型需求。

## 發佈

GitHub Pages 設定為 Deploy from a branch，選擇 main 分支及 / (root)。修改後推送至 main 即會重新部署。
